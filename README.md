# Project Overview

This project is a Memory Matching Game developed using Flutter and Dart. The application allows users to flip cards and match identical pairs. The game is designed with a clean and responsive user interface that works smoothly on Android devices and Flutter Web.

The main objective of this project is to improve memory and concentration skills through an interactive and user-friendly mobile application.



# Features

* Memory card matching gameplay
* Randomized cards each time the game starts
* Score tracking system
* Responsive and attractive UI design
* Restart game functionality
* Smooth card flipping animations
* Works on Android Emulator, Android Phone, and Chrome Web
  

#Technologies Used

* Flutter
* Dart
* Android Studio
* Material Design UI
