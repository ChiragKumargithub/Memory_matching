Project Overview
This project is a Memory Matching Game developed using Flutter and Dart. The application allows users to flip cards and match identical pairs. The game is designed with a responsive user interface that works on Android devices and Flutter Web.
The main objective of the project is to improve memory skills through an interactive and user-friendly mobile application.
Features
Memory card matching gameplay
Randomized cards each time the game starts
Score tracking
Responsive UI design
Restart game functionality
Smooth animations and card flipping effect
Works on Android Emulator, Android Phone, and Chrome Web
Technologies Used
Flutter
Dart
